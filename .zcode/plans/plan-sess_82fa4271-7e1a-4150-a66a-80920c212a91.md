Add laravel-lsp as a minimal headless, report-only feedback step. Server is already installed; no dependency changes.

## Changes

1. **`scripts/feedback/lsp.php`** (new, single file, ~80 lines, exit 0 always):
   - `shell_exec('git diff --cached --name-only --diff-filter=ACM -- app')`, keep `.php` files; early exit `lsp: no app files staged; nothing to report.` when empty.
   - Spawn `laravel-lsp` (override via env `LARAVEL_LSP_BIN`) with `proc_open`; when the binary is missing, print `lsp: laravel-lsp not installed; nothing to report.` and exit 0.
   - Minimal LSP over stdio with `Content-Length` framing: `initialize` → `initialized` → `didOpen` each staged file (working-tree content) → collect the latest `textDocument/publishDiagnostics` per file → `shutdown` → `exit`.
   - Finish when every file has published diagnostics or after a 60-second idle timeout, whichever first (the server gives no done signal).
   - Print one `lsp=file:line: message` per diagnostic, sorted; on clean print `lsp: no diagnostics.`; on protocol failure print what happened. No verdict, never fails.

2. **`scripts/feedback/verify.sh`**: add `run_report lsp php scripts/feedback/lsp.php` after the phpstan line (line 33).

3. **AGENTS.md**: add lsp to the report-only list in the verification paragraph.
