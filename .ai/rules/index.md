# Rules index

Each rule file lists the globs it covers. Read every file whose globs match the paths you are editing before you write code.

- `**/*.php` — `php-style.md`: strict types, final classes, promoted constructors, return types, comments ban.
- `tests/**` — `pest-testing.md`: Pest style, suites, parallel databases.
- `app/Models/**` — `models.md`: Eloquent model conventions.
- `app/**` — `app-architecture.md`: layer map, dependency rules, controllers, form requests, naming.
