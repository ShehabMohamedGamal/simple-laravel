# Grilling sessions

Applies to every session that opens a grilling interview: grill-me, grill-with-docs, wayfinder grilling tickets, planner elicitation.

Open the session with setup, in this order:

1. List the topics you can already see in the request. Name them; the dim ones stay dim.
2. Propose a session structure: which topic decides first, what hangs on it, roughly how many rounds.
3. Get the user's agreement on the structure. Adjust until agreed.
4. Create one todo per topic. Mark a topic completed the round it settles; add todos for topics the rounds surface.

Then run the grilling rounds. The frontier rule, the question format, and the rounds themselves belong to the grilling skill; this doc only adds the session setup.
